# Bakery, freezer and staff-area pack

57 editable prefabs, including three example layouts. All display units are empty for future 2D product artwork. Front faces local -Z; floor props have floor pivots and wall props use wall pivots. Dimensions are metres. Bakery shelves and upright freezer doors have named StockingSlots transforms. Door leaves sit under named hinges for manual posing; no interaction scripts are included. Upright freezers use 0.78m door bays; bakery wide shelves are 2.4m wide.

Prefabs are grouped into Bakery, Freezers, Staff, Props and Showcases. Contact sheets are in Previews. Copied pixel textures/materials, generated text meshes, the glass shader, and the generator are all within this folder. Uses Unity URP and built-in primitive meshes.

The generator refuses to replace an existing pack, protecting hand edits. Edit existing prefabs directly. Example layouts are prefab assets and have not been placed into Superstore.
